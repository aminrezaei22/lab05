=== 1. STRUCT ===
STRUCT:             Student
MODELS:             One student's name and their assignment scores.
LIVES IN:           include/student.h - grading, printing, main, and tests all need it.
FIXED DIMENSION:    Number of assignments - every student has the same assignments.
VARYING DIMENSION:  Number of students - passed as student_count with the array.

FIELDS:
  - std::string name;
  - double scores[assignment_count];     // constexpr int assignment_count{5};

COLLECTION PASSED AS: const Student* students, int student_count

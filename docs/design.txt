=== PHASE 3: DESIGN THE RECORD ===
STRUCT:             Student
MODELS:             One student's full name and their corresponding assignment scores.
LIVES IN:           include/grading.hpp 
FIXED DIMENSION:    Number of assignments, because every student takes the same fixed set of assignments.
VARYING DIMENSION:  Number of students on the roster, passed as a runtime count alongside the collection pointer.

FIELDS:
  - std::string name;
  - double scores[assignment_count];

COLLECTION PASSED AS: const Student students[], int student_count

=== PHASE 4: SIGNATURE TABLE ===
FUNCTION:           print_student_names
MODULE:             src/printing.cpp
OLD:                void print_student_names(const std::string names[], int count)
NEW:                void print_student_names(const Student students[], int student_count)
PARAMETER REASONS:  Receives the full roster collection pointer and runtime count to loop through all records safely.
CONTRACT CHANGES:   none

---

FUNCTION:           calculate_student_average
MODULE:             src/grading.cpp
OLD:                double calculate_student_average(const double scores[][MAX_ASSIGNMENTS], int student_index)
NEW:                double calculate_student_average(const Student& student)
PARAMETER REASONS:  Now takes a single Student reference instead of a 2D array and an index, because a student record already contains their own scores!
CONTRACT CHANGES:   none (still returns the average score for that student)

=== PHASE 5: CONVERSION ORDER ===
1. include/grading.hpp & src/grading.cpp (Update struct definition and grading functions)
2. include/printing.hpp & src/printing.cpp (Update printing functions to use Student struct)
3. src/main.cpp (Update main logic and roster collection)
4. tests/ (Update test fixtures and test cases to use the new Student records)

NOTE ON TEST SUITE & CONTRACTS: 
The test suite will be red after step 1 and 2 until step 4 updates the test fixtures. This is expected. Empty roster behavior for class_average should return 0.0 or be explicitly handled.
